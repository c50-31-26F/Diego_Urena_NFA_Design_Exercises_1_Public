# Diego_Urena_NFA_Design_Exercises_1
I learned that many of these NFAs looked pretty similar to how they would look if they were instead DFAs. Most of the first few problems only saved on maybe 1 or 2 states or transitions. However, the NFA's become a lot more useful the more complex your language is. For example, {string s | second to last bit is a 1 } became a lot simpler to model with an NFA instead of a DFA. What I had trouble with in this assignment was understanding how Epsilon transitions actually worked. I tried looping a state to itself with an Epsilon transition until it found the "1" symbol that my NFA's accept state was dependent on. However, I had a conversation with ChatGPT and after asking him to double check and find information from real resources, I had learned that having an Epsilon loop like this would never actually consume any 0's, therefore, the NFA would end up getting stuck on any 0 symbols in a string and never read the rest. This would have completely broken my NFA. This was the only question I had asked ChatGPT. For the rest of the problems, I worked through them myself and took the time to avoid being incorrect or adding redundant transitions.
